\section{Excess edits: an XP-in-\texorpdfstring{$\ell$}{l}, FPT-in-\texorpdfstring{$w$}{w} algorithm}\label{sec:excess}
\begin{theorem}\label{thm:A}
Given $(G,H,\ell)$ and a tree decomposition of $I(H)$ of width $w$, CEaMP is solvable in $7^{w+1}n^{2\ell+O(1)}$ time.
\end{theorem}
\begin{proof}
Let $\mathcal D_i$ be the $7$ non-empty subsets of $\pairs(P_i)$. By Lemma~\ref{lem:decomp}, a solution of size $\le|H|+\ell$ has the form $S=U\cup\bigcup x_i$ with $x_i\in\mathcal D_i$ and $U$ a set of at most $\ell$ unpacked pairs; there are at most $\sum_{j\le\ell}\binom{n^2/2}{j}\le n^{2\ell}$ candidates for $U$.

Fix $U$ and put $G_U=G\sd U$. Since $U$ avoids packed pairs, every $P_i$ is still an induced $P_3$ of $G_U$ with the same pairs, so $H$ is still a modification-disjoint packing. For a triple $t$, the status of each unpacked pair of $t$ in $G_U\sd x$ is fixed, and each packed pair is determined by $G_U$ and the variable of its owner. Hence $t$ gives a constraint $C_t$ (``$t$ is not an induced $P_3$ in $G_U\sd x$'') whose scope is the owner set of $t$, a clique of $I(H)$ by Observation~\ref{obs:two} (the proof there does not use $G$ itself). Triples with empty scope are tested directly, in $O(n^3)$ time. Seek $x\in\prod\mathcal D_i$ satisfying all $C_t$ and minimizing the unary cost $\sum_i|x_i|$.

Let $(T,\{B_s\})$ be the tree decomposition. By the Helly property each clique lies in a bag; assign each constraint to one such bag. For a node $s$ and an assignment $\alpha$ of $B_s$, let $f_s(\alpha)$ be the minimum cost of $\sum|x_i|$ over variables in the subtree of $s$, among assignments extending $\alpha$ and satisfying all constraints assigned in the subtree. The standard recurrences (introduce, forget, join; see~\cite{Cygan15}) compute all $f_s$ in time $7^{w+1}n^{O(1)}$ since there are $O(n^3)$ constraints and each table has $\le7^{w+1}$ entries. Accept iff for some $U$ the minimum $m_U$ satisfies $m_U+|U|\le|H|+\ell$. Soundness: any feasible $(U,x)$ gives the solution $U\cup\bigcup x_i$. Completeness: Lemma~\ref{lem:decomp}.
\end{proof}
\begin{remark}[Why domain size $7$]
The empty value is never feasible, so $7$ (not $8$) suffices. It cannot be lowered to $3$: an edited packed $P_3$ can receive two or three edits in every optimum. For two: $n=5$, $E=\{02,04,12,23,24\}$, $H=\{(1,2,3)\}$, $\OPT=2$, unique optimum $\{12,23\}$. For three: $n=6$, $E=\{01,02,03,04,12,14,15,24,25,35,45\}$, $H=\{(0,3,5)\}$, $\OPT=3$, unique optimum $\{03,05,35\}$ (both checked exhaustively over all set partitions). In the notes' random data (computer evidence, $n\le9$) about $8$--$9\%$ of instances force $\ge2$ edits on some packed $P_3$ and $\approx0.2\%$ force three. For $c=2$, $I(H)$ is subcubic but may have unbounded treewidth, so Theorem~\ref{thm:A} is a different tradeoff from, not a recovery of, the $n^{2\ell}$ algorithm of~\cite{LPS23}.
\end{remark}
\begin{proposition}[Completing a fixed packed assignment]\label{prop:B}
Let $x$ assign a subset $x_i\subseteq\pairs(P_i)$ to each $P_i$ and let $B=|H|+\ell-\sum|x_i|$ be the excess budget left. Whether there is a set $U$ of at most $B$ unpacked pairs with $G\sd(x\cup U)$ a cluster graph is decidable in $3^{B}n^{O(1)}$ time.
\end{proposition}
\begin{proof}
Search tree on $G_x=G\sd x$: if the current graph has an induced $P_3$, some pair of it must be flipped; packed pairs are frozen by $x$, so branch on its at most three unpacked pairs, reducing $B$ by one (if all its pairs are packed, reject). Depth is at most $B$; flipping a pair twice is useless, so the search is exhaustive.
\end{proof}
\begin{remark}
Proposition~\ref{prop:B} is a reformulation, not progress towards FPT in $(\ell,w)$: finding $x$ is the whole problem, and the property ``$x$ is completable'' is not local in $x$.
\end{remark}
