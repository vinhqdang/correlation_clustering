## (4) Lemma F.6 (tmaj)

Re-derived. (1) An anchor that is a centre of a member is never a singleton in a ZE solution (two edges at x would both be edited), so {x} is a non-face, contradicting minimality of the core S (|S| >= 3). Two end-anchors a, c of one member force states 1 and 2 respectively, so {a,c} is a non-face and a proper subset of S. Hence every member through an anchor of S has exactly one anchor of S and it is an end. (2) The forced vector t on T (members through anchors of S) is conflict-free, and S is a face iff t is in proj_T(Sigma) (first statement of Lemma F.3). |T| >= |S| >= 3 because distinct anchors lie in distinct members. (3) Baker-Pixley by the three-vector induction: correct, with the base case |T| = 2 (see fix 5). (4) A pair P,P' of T with (t_P,t_P') outside the binary projection gives S' = anchors of S in P or P', |S'| <= 2 < |S|, which forces t_P,t_P' and hence is a non-face: contradiction with minimality. So every core has <= 2 anchors; "<= 1 anchor per member" and "<= 2 anchors" both proved. Hypotheses: only majority closure of Sigma and the definition of core (Sigma empty gives the core empty set, fine).
Computer: `code/r2_tmaj.py` verified Example F.11 exactly (Sigma = {1111,1313,3131,2222}; closed under the value-1 majority, not under m_3). Random tight instances (3 x 1430, n <= 9, c arbitrary, 3..8 anchors): maximum core size found was 2 in every instance, so the random test never produced a core of size >= 3 and is vacuous as a test of the lemma. The proof is therefore the only support, and it is sound. G* (Example F.10) checked: five ZE solutions exactly as stated, 22233 pairwise consistent but not a solution.

## (5) ETH proof against LPS23

- LPS23 Sec. 4 (lps.txt 246-330, 770-830): reduction from 3-CNF; every variable x_i gets 4 m_i cliques of 5 vertices, every clause a constant number of cliques of fixed sizes (Q^1..Q^4 of sizes 1,14,4,1; transferring cliques of sizes 34, 46, 34 for the three variables), padding vertices are added inside these cliques only, hence |V| = O(sum_i m_i + m) = O(m) (and N <= 3m/2 by the "every variable appears twice" preprocessing), so the paper's "|V| = O(N+m)" is correct (even O(m)). "Each vertex is in at most 23 P3s of H": line 829-830. Theorem 1: lines 104-106. The reduction maps 3-CNF with exactly 3 distinct variables per clause, l=0.
- With sparsification (IPZ01), m = O(N) at 2^{o(N)} cost; 3|H| = sum_v #{P∋v} <= 23|V| gives |H| <= 23|V|/3 = O(N); one bag with all members is a tree decomposition of I(H), so tw(I(H)) <= |H|-1 = O(N); a 2^{o(tw)} n^{O(1)} algorithm (n = |V| = O(N), poly) gives 3-SAT in 2^{o(N)}: contradiction. Degree bound: a member meets at most 3*22 = 66 others (two members share at most one vertex). The monotonicity step (o(tw) with tw <= cN implies o(N)) is valid for a constant c.
- "No 2^{o(w)} even at l=0, c <= 23" in the abstract/Thm 1.1(c): correct as stated. Note it is a statement about the exponent for a worst-case family with w = Theta(N); it does not say that w small implies the DP is needed.
- The only defect is Remark (2) after the theorem (fix 1).
