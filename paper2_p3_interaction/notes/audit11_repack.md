## 1. Exchange calculus, twin lemma, witness dichotomy (a11_exch.py, a11_overlap.py)

Setup of the test: random graphs n = 6..10 (density 0.25/0.35/0.5), random greedy pair-maximal packing H, **all optimal partitions** (ground truth), every hard edit of every optimum. Seeds 2-5: 5,867 instances, 25,899 optima, 26,387 hard edits (seed 1 adds 149 / 675 / 627).

**Lemma 2.1.** Hand check: pair sets disjoint by hypothesis, size unchanged, I(H') - T = I(H) - Q is an induced subgraph, one extra vertex adds at most 1 to tw. Correct. Computer: in 27,177 single exchanges H - Q + T (T = a witness with exactly one soft pair): always a modification-disjoint packing, size |H|, e soft afterwards, tw(I(H')) <= tw(I(H)) + 1 (exact tw), 0 violations.
Fix 1 (pair-maximality): the new packing is pair-maximal in only 16,079 of 27,177 cases (59%); 11,098 (41%) are not (the two other pairs of Q become hard and can complete an all-hard P3). The wave-8 text asserts pair-maximality only for FAR (true, checked), but Cor 2.4, REPACK-XP step 3 and the application of PL/Cor cand to H* all silently need it. The repair is Lemma MAX: H* = H' + M, |M| <= l (M is a family hard over H', so |H'| + |M| <= OPT <= |H| + l), width <= tw + 1 + |M|, excess drops by |M|. This does not change any verdict but must be stated; "tw + 1" is the width of H - Q + T, not of the packing one can feed to PL.
Fix 2: "j simultaneous exchanges give <= w + j" requires Q_1..Q_j distinct and the T_i pairwise pair-disjoint and avoiding the pairs of H - {Q_i}; as written this follows only for sequential exchanges (each applied to the current packing).
The side remark (T with two soft pairs gives a packing of size |H| - 1) is true and irrelevant.

**Lemma 2.2 (twins).** Proof re-derived: a, b closed twins in different clusters; a move of a into b's cluster costs 2 c_b, a move of b costs 2 c_a, against c_a + c_b + 1; min(2c_a, 2c_b) <= c_a + c_b < c_a + c_b + 1. Correct (empty-cluster case harmless). Computer: 1,634 closed-twin pairs, in all optima never separated. Consequence "every hard edit of an optimum lies in an induced P3 of G": 0 exceptions among 26,387 edits (inserted: Lemma half(b); deleted: twin lemma). Correct, though I would not call it new: it is the standard fact that optimal Cluster Editing solutions have only edits that are in an induced P3.

**Lemma 2.3.** Both subcases verified: every witness has 1 or 2 soft pairs (never 0 or 3: 0 violations), with two soft pairs the owners are distinct, both contain the shared vertex z and a lies in one, b in the other (0 violations over all two-soft witnesses), without a two-soft witness the exchange of 2.3(b) works (0 failures).
**Gap (text, not substance):** 2.3(a) says the two soft pairs share "the middle vertex of T". For an inserted pair e = ab, T = (a, z, b), soft pairs az, zb share the centre z: true (0 counterexamples). For a **deleted** pair e = ab, the witness is T = (x, b, a) with soft pairs xb, xa that share the *end* x opposite to e: 11,433 of the tested two-soft witnesses have the shared vertex not at the centre, all of them for deleted edits. Correct statement: "share a vertex z (the centre of T when e is inserted, the end opposite to e when e is deleted)". The conclusion P != P', z in P cap P', a in V(P'), b in V(P), hence A-local, is right in both cases; the identification with type T1 of the paper holds only for inserted edits.
Remark: "absorbable vs T1 dichotomy" is a case split, not an exclusive dichotomy: of 6,595 hard edits, 2,699 (41%) have witnesses of both kinds, 832 only two-soft witnesses, 3,064 only one-soft witnesses. Cor 2.4 ("not A-local implies absorbable") is correct as stated.
New fact needed by PL (proved here): **no hard edit of an optimum has both ends uncovered.** A witness T of e = {r, r'} has third vertex x and pairs {r,x}, {r',x}, both hard because r, r' lie in no member; so T would have all pairs hard, contradicting pair-maximality (and Lemma 2.3 gives the witness). Computer: 0 of 26,387.

**Lemma 2.5.** Hand proof re-checked (az kept, Q = {a,z,r} induced, exactly one of ar, zr an edge; in-cluster r keeps the edge and inserts the non-edge, out-of-cluster r deletes the edge, so exactly one edit f in Q). Computer: 5,027 inserted edits with z in the cluster: Q has exactly one edit, new hard set = U - e + f, f at r, 0 violations. r is uncovered after the exchange in 1,650 cases, still covered in 3,377 (67%), so the defect usually moves; termination remains open as the note says.

## 4. Theorem PL: real implementation (a11_pl.py, a11_pl_far.py, a11_pl_sp.py)

Implemented from the proof text: tree decomposition of I(H) from random elimination orders (so co-bagging varies); state at a bag = (x_P for the members of the bag, E_v for every covered v in X_t cap L_B), labels restricted to Elig(v) = hard partners in Ball(v) (radius 2 in G[L_B]) that are covered, in L_B and co-bagged with v, or uncovered local hubs, |E_v| <= l; checks at a bag: symmetry (S) for all labelled pairs, and **every vertex triple of V whose three pair statuses are visible at the bag** (soft pair: owner in the bag; hard eligible covered pair: one end labelled in the bag; hard hub pair: the covered end labelled; everything else statically unedited); costs charged at the top bag of each item; join = equality of the shared state. The code also computes, independently of the DP, by enumerating all partitions, CLASS-OPT = min size of a partition all of whose hard edits are eligible with |E_v| <= l, and checks that every triple is verified at some bag (coverage).

Results (random instances n = 6..9, random pair-maximal H with |H| <= 5, width <= 2, l = max(1, OPT - |H|) or OPT - |H|; plus sparse "tree + chords" instances with 3 <= |H| <= 6):
* 984 instances (807 random + 177 sparse): **0 soundness violations (DP value >= OPT always); DP value = CLASS-OPT in all 984** (so the DP is exact on the class, not only sound); **0 completeness failures among the 948 instances where some optimum is in the class**; the 36 instances with no optimum in the class all have DP value > OPT (as the theory predicts); **0 coverage failures** (every triple is verified at some bag).
* FAR_m, m = 3, 4, 5: path tiling H_0: DP = m + 2 = OPT + 1 (promise fails, equals CLASS-OPT; the YES instance (G, H_0, 1) is **rejected**, so the algorithm is genuinely incomplete off the promise); exchanged H*: DP = m + 1 = OPT.
* Sp(triangle), original H: DP = 9 = OPT (n = 18).
* Negative controls (harness can fail): allowing non-co-bagged covered partners / any hub (`loose`): **17 of 177 instances give DP < OPT (unsound)**; the variant without the symmetry check (S) (`noS` mode of `a11_pl.py`) was written but its un-pruned state space was too slow to finish in this session, so that control is **not** reported; (S) is justified by the hand argument only (an edit counted from one side with the partner unconstrained on the other is not a pair of S). The co-bagging restriction is the one demonstrated essential.

Verdict CORRECT WITH FIX. The proof is right; the following must be added:
1. **Label domain.** The proof text says "a label E_v subset of Ball(v)" and puts co-bagging only in the definition of the class. The DP must restrict E_v to Elig(v) (covered partner co-bagged with v; uncovered partner a local hub); otherwise the symmetry check (S) cannot be enforced for far partners and the DP is unsound (17/177 above). The same holds for the soundness note ("two edits at r with far partners could not be matched").
2. **Uncovered-uncovered edits.** The class has no edit between two uncovered vertices. This is no loss: the lemma above shows no optimum has such an edit.
3. **Visibility argument made explicit** (the proof says "determined at t" without the reason): every triple is covered by two of its vertices, and the DP needs a bag containing those two (for a hard-edit triple: the co-bagged ends of the eligible pair; for a hub pair {r, v} with another edited pair {r, c}: both v, c in Ball(r), pairwise co-bagged by the hub condition, Helly). The computer coverage check is the finite confirmation.
4. **One-sidedness.** "Promise-FPT" is a misnomer: the promise (an optimum lies in the class) cannot be tested, m* > |H| + l does not certify NO. Correct description: an FPT-time one-sided algorithm that certifies YES and is exact on the class. This matters for Remark 4.0: "incomparable with Theorem omega" compares an unconditional algorithm with a one-sided one.
5. Corollary 4.1 wording: "a link between the members of the two ends" is ambiguous; co-bagging needs some member through a and some member through b in a common bag, so w_Lambda is a minimum over the choice of the linked members.
Running time: states 7^{w+1} (Z^2 + 1)^{3 l (w+1)} per bag with |X_t| <= 3(w+1), Z = 3D + 3l + 1, D <= 2(w+1): re-derived, correct.

## 5. Theorem N, LPS23 and the two "Theorem A"s

(a) Proof logic: at l = 0 CEaMP is NP-hard (LPS23, via the paper); a hypothetical polynomial procedure outputs H*; (G, H*, l*) with |H*| + l* = |H| + l is equivalent; Theorem A of the **paper** (7^{w+1} n^{2l+O(1)}, valid for every packing, proof in `csp.tex`, no soft-triangle or other hypothesis) decides it in polynomial time because w <= f(0) and l* <= s(0) are constants. **The audit-10 remark does not apply**: audit 10 notes that the LPS gadgets contain soft triangles (100 in one variable gadget), which excludes only the wave-7 majority theorem (polynomial l = 0 for soft-triangle-free instances). Thm N never uses that theorem. The NP-hardness argument is valid, and consistent with wave 7: it would be contradicted only if one applied the wave-7 theorem to LPS instances. Rename one of the two theorems.
Fix: the guarantee "tw(I(H*)) <= f(l), excess <= s(l)" holds only on YES inputs. The reduction must (i) test that H* is a modification-disjoint packing of induced P3s of G, (ii) compute a width-f(0) decomposition (linear time for constant width, else reject), (iii) test l* = |H| - |H*| in [0, s(0)], reject otherwise, and only then run Theorem A. All rejections are correct on NO instances and unreachable on YES instances, so the argument is sound; as written the running time of the last step is not bounded for adversarial outputs. Also: the proof only uses l = 0, so "functions s, f of l" is cosmetic and the theorem says nothing for l > 0.
(b) ETH form: re-derived: with |H*| = |H| = O(N) (paper's Thm eth proof, after sparsification) and tw(I(H*)) <= |H|^{1-eps}, a 2w+1 approximate decomposition in 2^{O(w)} n time and Theorem l0 (3^{w+1} n^{O(1)}) give 2^{O(N^{1-eps})}, contradicting ETH. Correct. (|H*| >= |H| is automatic for l = 0 YES instances; |H*| < |H| is excluded by the stated hypothesis.)
Remarks "tight instances have no better packing" and "if tw is large then reject is false": correct (tight instances l = 0, nu = OPT = |H|).
