# Certificates

- `colab/`: the certificates and clusterings behind every checked bound and
  archived clustering reported in the paper (runs on the Colab machines),
  re-checked in `results/mpc/recheck.csv`.
- `../local/certs/`: the certificates of the 1800 s bound runs on every fourth
  PACE exact instance (laptop), re-checked in `results/mpc/recheck_local.csv`.
- `pace-exact/`, `snap/`: certificates of an earlier version of the method
  (before the instance identity fields and the final checker); kept for the
  record, not used for any number in the paper.
